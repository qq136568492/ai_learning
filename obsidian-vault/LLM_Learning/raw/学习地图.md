**目标**：写出 Pythonic 且可直接部署生产环境的代码，复用 Java 的工程思维。

| 知识模块 | 说明 | 必学知识点 | 🔗 学习链接 |
|----------|------|------------|--------------|

| **环境与包管理** | 虚拟环境、依赖锁定、现代工具链 | `venv`、`poetry`、`uv` | [Poetry 文档](https://python-poetry.org/docs/) ，[uv 文档](https://docs.astral.sh/uv/) |

## 🏗️ 实战路线图（按顺序动手）

1. **数据处理项目**：用 Pandas + NumPy 清洗一份 10 万行以上的 CSV 数据，并用 FastAPI 提供数据查询 API。  
2. **本地聊天机器人**：用 Ollama 部署 `qwen3`，通过 FastAPI 封装成流式对话接口。  
3. **RAG 知识库问答**：用 LangChain + Chroma 构建个人技术文档问答系统，支持 PDF 上传与提问。  
4. **Agent 工具调用**：让模型能够调用搜索 API 或计算器，完成“查询今日天气并总结”任务。  
5. **企业级部署**：将上述任一件品 Docker 化，编写 GitHub Actions 做自动化测试，接入 Prometheus 监控。

## 💡 给 Java 工程师的额外建议
- **迁移你的强项**：依赖注入（FastAPI 的 Depends）、事务管理（上下文管理器）、分层架构都是你熟悉的，放心在 Python 中使用。  
- **不必死磕算法**：前期只需会用预训练模型，就像使用数据库一样，把 LLM 当作一种新的计算资源。  
- **善用类型**：Pydantic + mypy 能给你类似 Java 的编译期安心感，重度使用它们。  
- **多读优秀开源项目源码**：如 [langchain-chatchat](https://github.com/chatchat-space/Langchain-Chatchat)、[Dify](https://github.com/langgenius/dify)，学习工程化落地思路。
