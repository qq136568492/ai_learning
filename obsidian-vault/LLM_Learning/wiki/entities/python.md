# Python

解释型、动态类型、面向对象的高级编程语言。由 Guido van Rossum 于 1991 年首次发布，命名源自 BBC 的 "Monty Python 飞行马戏团"。

## 核心特征

- **解释型**：无需编译链接，交互式开发
- **动态类型**：变量无需预声明类型
- **多范式**：面向对象、函数式、过程式
- **缩进语法**：用缩进而非括号组织代码块
- **自带电池**：丰富的标准库

## 设计哲学

- 易读性优先（PEP 20: The Zen of Python）
- 一种明显的做法（"There should be one obvious way to do it"）
- 简洁胜于复杂

## 版本信息

本 wiki 当前基于 **Python 3.11** 的官方教程。3.10+ 引入了 match 语句（结构化模式匹配）。
