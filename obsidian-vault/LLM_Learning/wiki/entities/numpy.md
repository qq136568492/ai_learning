# NumPy

NumPy 是 Python 数值计算基础库，核心提供 `ndarray` 多维数组与向量化计算能力，是 Pandas、SciPy、scikit-learn、PyTorch 等生态的重要底层依赖。

## 关键特性
- 同构多维数组（`ndarray`）
- 广播机制（broadcasting）
- 通用函数（ufunc）与按轴聚合
- 精细 dtype 与内存控制
- 与 C/C++/Fortran 及外部数组容器互操作
