# FastAPI

FastAPI 是基于 Starlette 与 Pydantic 的 Python Web API 框架，强调高性能、类型驱动开发与自动 OpenAPI 文档生成。

## 关键特性
- 类型注解驱动的请求解析与校验
- 自动生成 Swagger UI / ReDoc
- 原生支持 async/await
- 依赖注入机制（Depends）
- 与 Pydantic、Uvicorn 等生态深度配合
