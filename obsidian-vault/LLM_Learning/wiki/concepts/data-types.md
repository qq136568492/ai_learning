# 数据类型

Python 内置的核心数据类型，分为不可变（immutable）和可变（mutable）两大类。

## 不可变类型

| 类型 | 示例 | 说明 |
|------|------|------|
| int | `42`, `0xff` | 任意精度整数 |
| float | `3.14`, `1e-3` | 双精度浮点数 |
| complex | `3+4j` | 复数 |
| str | `'hello'`, `"world"` | Unicode 字符串 |
| tuple | `(1, 2, 3)` | 不可变序列 |
| frozenset | `frozenset({1,2})` | 不可变集合 |
| bool | `True`, `False` | 布尔值（int 的子类） |
| None | `None` | 空值单例 |

## 可变类型

| 类型 | 示例 | 说明 |
|------|------|------|
| list | `[1, 2, 3]` | 可变有序序列 |
| dict | `{'a': 1}` | 键值映射 |
| set | `{1, 2, 3}` | 无序不重复集合 |

## 关键规则

- **赋值不复制**：`a = b` 让两个变量指向同一对象
- **可变默认值陷阱**：函数默认参数只求值一次，可变对象会在调用间共享
- **字典键必须不可变**：list 不能做键，tuple 可以（前提是其元素也不可变）
- **序列通用操作**：索引、切片、`+`（拼接）、`*`（重复）、`in`（成员检测）、`len()`

## str 要点

- 不可变：不能 `s[0] = 'x'`，只能创建新字符串
- 支持索引和切片，负索引从右计数
- 原始字符串 `r'...'` 不转义反斜杠
- 三引号 `'''...'''` 支持多行
- f-string `f'{expr}'` 内嵌表达式（详见 [[concepts/string-formatting]]）

## list 要点

- 可变序列，支持异质元素
- 切片赋值可改变长度：`a[2:5] = []`
- 常用方法：append、extend、insert、pop、remove、sort、reverse
- 用作栈（append/pop）效率高，用作队列应改用 `collections.deque`

## tuple 要点

- 不可变，通常存放异质数据
- 单元素元组需尾逗号：`(42,)`
- 支持解包：`x, y, z = (1, 2, 3)`

## dict 要点

- 键值对集合，键必须可哈希
- 3.7+ 保持插入顺序
- 推导式：`{k: v for k, v in pairs}`

## set 要点

- 无序、不重复
- 支持数学运算：`|`（并）、`&`（交）、`-`（差）、`^`（对称差）
- 创建空集合用 `set()`，不能用 `{}`（那是空字典）
