# Learn Python 全课程章节练习（精简版）

## 练习结构
按视频章节分 6 组，每组完成 1 个小项目。

1. **基础语法组**（变量/字符串/数字/输入）
   - 做一个“单位换算器”（长度/温度二选一）。
2. **容器与函数组**（list/tuple/dict/function/return）
   - 做一个“学生成绩查询器”（字典存储，函数封装查询）。
3. **流程控制组**（if/while/for）
   - 做一个“猜数字游戏”，支持次数限制与提示。
4. **异常与文件组**（try-except/read/write）
   - 做一个“记账文本工具”，非法输入不崩溃。
5. **模块与包组**（module/pip）
   - 拆分为 `main.py` 与 `utils.py`，并引入一个三方包。
6. **OOP 组**（class/object/inheritance）
   - 做一个“题库测验器”（题目类 + 测验类 + 派生类扩展）。

## 完成标准（DoD）
- 每组代码可运行
- 每组至少 1 个输入边界测试
- 最终项目结构包含 README（运行方式 + 功能说明）
