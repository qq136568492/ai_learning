# NumPy 数值计算基础

该主题聚焦 AI 工程前置的数据处理能力：用 ndarray、广播与 ufunc 进行高效向量化计算。

## 核心能力块
- ndarray 心智模型：shape / ndim / dtype / axis
- 向量化计算：逐元素运算、聚合、矩阵运算
- 广播规则：不同维度数组对齐计算（[[concepts/broadcasting-rules]]）
- 内存语义：view vs copy（[[concepts/view-vs-copy]]）
- dtype 与字节序：精度、内存、跨平台兼容（[[concepts/dtype-and-memory]]）
