# LLM 工程师学习路线

该主题聚焦 `mlabonne/llm-course` 中 The LLM Engineer 路线：如何构建、增强、部署与保护 LLM 应用。

## 核心模块
- Running LLMs：API、本地模型、Prompt、结构化输出
- Building a Vector Storage：文档加载、切分、embedding、向量数据库
- Retrieval Augmented Generation：检索器、记忆、RAG 评估
- Advanced RAG：查询构造、工具、重排、DSPy
- Agents：工具调用、MCP/A2A、LangGraph、LlamaIndex Agents
- Inference Optimization：Flash Attention、KV Cache、Speculative Decoding
- Deploying LLMs：本地/演示/服务端/边缘部署
- Securing LLMs：Prompt Injection、数据泄漏、红队测试、观测
