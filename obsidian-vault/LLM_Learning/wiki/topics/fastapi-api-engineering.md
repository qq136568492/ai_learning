# FastAPI API 工程化实践

面向生产环境的 FastAPI 学习与落地主题，覆盖接口设计、依赖注入、安全、测试与部署。

## 核心能力块
- 接口建模：Path/Query/Body + Response Model
- 数据契约：Pydantic 校验与序列化
- 依赖注入：认证、数据库会话、配置管理（[[concepts/dependency-injection]]）
- 安全：OAuth2/JWT、CORS、中间件（[[concepts/api-security]]）
- 工程化：测试、Docker、worker、代理与 HTTPS（[[concepts/deployment-strategy]]）
