# LLM Scientist 学习路线

该主题聚焦 `mlabonne/llm-course` 中 The LLM Scientist 路线：理解并改进 LLM 本身，包括架构、训练、后训练、量化、评估与模型合并。

## 核心模块
- LLM Architecture：Transformer、tokenization、attention、sampling
- Pre-training Models：数据准备、分布式训练、优化与监控
- Post-training Datasets：SFT 数据、偏好数据、chat template
- Fine-tuning / Alignment：QLoRA、DPO、ORPO 等
- Quantization：8-bit、4-bit、GGUF、GPTQ、EXL2、AWQ
- Evaluation：自动评估、人类评估、benchmark 与任务指标
- Advanced topics：model merging、多模态、mechanistic interpretability、test-time compute
