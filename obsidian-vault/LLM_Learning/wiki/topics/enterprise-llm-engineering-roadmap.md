# 企业级 LLM 应用工程化学习路径

面向 Java 工程师的端到端学习路线：从 Python 工程能力，到 LLM 应用开发，再到生产环境部署与运维。

## 分阶段主线
1. Python 工程化基础（类型、测试、异步、包管理）
2. 数据处理基础（NumPy/Pandas/可视化）
3. API 服务开发（FastAPI + Pydantic）
4. LLM 调用与 Prompt 工程
5. RAG / Agent 复杂应用
6. 向量数据库与检索层
7. 微调与推理部署
8. 企业级工程化落地（Docker、CI/CD、监控、安全）

## 方法论
- 先“可运行原型”，再“可观测与可维护生产系统”。
- 复用 Java 工程经验：分层架构、依赖注入、服务治理。
- 不把算法理论作为前置门槛，优先掌握调用与系统集成。

## 推荐实战顺序
- 数据清洗 API 项目
- 本地模型聊天服务（Ollama）
- PDF RAG 问答系统
- Agent 工具调用任务
- Docker + CI/CD + 监控的生产化改造
