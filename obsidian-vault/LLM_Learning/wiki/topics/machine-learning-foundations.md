# 机器学习入门基础

该主题用于承接 Python/NumPy 数据处理能力，并为 AI 应用开发补齐传统机器学习的基础概念：数据集、特征、标签、监督学习、无监督学习、模型训练与评估。

## 核心模块
- 数据与特征：features、labels、feature matrix `X`、target vector `y`
- 监督学习：分类、回归、训练/验证/测试划分
- 常见分类算法：KNN、Naive Bayes、Logistic Regression、SVM、神经网络
- 常见回归算法：Linear Regression、神经网络回归
- 无监督学习：K-Means 聚类、PCA 降维
- 工具链：Google Colab、Pandas、NumPy、Matplotlib、scikit-learn、TensorFlow
