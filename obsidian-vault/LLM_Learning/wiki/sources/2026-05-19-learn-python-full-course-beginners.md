# Learn Python - Full Course for Beginners Tutorial

## 摘要
freeCodeCamp 的 Python 入门长视频课程（Mike Dane），适合作为新手从 0 到 1 的集中训练素材。

## 核心论点
- 以项目穿插语法点（计算器、Mad Libs、猜词、文件读写、小测验），学习曲线平滑。
- 覆盖 Python 入门主干：变量、字符串、数字、容器、函数、条件、循环、异常、文件、模块、面向对象。
- 可作为 [[topics/python-fundamentals]] 的视频化入口，并衔接 [[topics/python-advanced-to-ai-roadmap]]。
