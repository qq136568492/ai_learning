# 实战与 Demo

本目录位于**仓库根**，与 `learning/` **同级**，用于存放**面向实战的 demo 与小型项目**（与 `learning/` 下各子工程中偏「练习/包结构」的代码区分）。

- 可在此建子目录，例如 `demo-data-pipeline/`、`demo-fastapi-orders/`，每目录自含 `README` 说明如何运行与依赖范围。
- 当前与 **Python 进阶**子工程配合时，可编辑安装目标为 `learning/python-advanced-learning/python进阶/`，或把公共逻辑再抽回子工程内。

初期可为空；有第一个 demo 时在此添加子目录即可。
